# 11 — обработка заказов Organicare (Гонконг)

Инструмент для превращения текста заказа (по столам, премиум/стандарт,
исключения по составу) в готовый файл раскладки `.xlsx` в формате, принятом
на кухне (см. `docs/ПРАВИЛА_ОБРАБОТКИ.md`).

## Структура

- `docs/ПРАВИЛА_ОБРАБОТКИ.md` — правила обработки (накопленный опыт).
- `data/all_recipes.json` — состав блюд (аллергены/категории).
- `data/full_menu.json` — меню по дням недели.
- `src/composition.py` — сопоставление состава блюда с исключением
  (лактоза/рыба/мясо/злаки/цитрус/орехи/... с учётом синонимов и
  спец-случаев вроде "мускатный орех" и "яйцо куриное").
- `src/order_grid.py` — заказ на конкретную дату: столбцы (столы/исключения),
  количества и сетка блюд по приёмам пищи. Каждое отступление от "наивной"
  раскладки помечено комментарием `# FIX`.
- `src/validate.py` — самопроверка состава: для каждой строки и каждого
  назначенного ей столбца проверяет, что блюдо не нарушает исключение.
- `src/coverage.py` — самопроверка покрытия: у каждого курса (салат/суп/...)
  каждый стол должен получить ровно одно блюдо (без повторов и "дыр"), кроме
  явно задокументированных исключений.
- `src/build_xlsx.py` — сборка итогового `.xlsx` (стили сняты с эталонного
  файла: шрифты Nunito/Arial, заливки, границы, ширины столбцов).
- `src/run.py` — запускает самопроверки и собирает файл.

## Запуск

```
cd src
python3 run.py
```

Файл сохраняется в `output/`.

## Заказ на 22.08.2026 (СБ) — что исправлено относительно черновой обработки

1. Столбцы R..U форматируются тем же циклом, что и остальные - не может
   визуально отличаться от D..Q.
2. Боулы (`БОУЛ ОВОЩНОЙ`) назначаются только премиум-столбцам (F..L) -
   раньше попадали и в стандарт, хотя боулы для стандарта не положены.
3. Вегану (U) на гарнир на обеде теперь один пункт (спагетти - стандартный
   гарнир дня), а не три одновременно (спагетти + рис с кукурузой +
   запечённые овощи).
4. Удалены пустые строки-артефакты без названия блюда и без данных.
5. Сливочное масло убрано у всех столбцов с исключением по лактозе
   (F, H, K, Q, S) - раньше выдавалось всем включая "без лактозы".
6. Дополнительно найдено и исправлено программной самопроверкой (не было в
   списке из чата, но всплыло при проверке состава):
   - лимон убран у S (без цитрусовых);
   - "Щи с курицей" убраны у R (без курицы) → заменены на суп-крем брокколи;
   - "Салат Грузинский" (с грецким орехом) убран у H (без орехов) → добавлен
     "Овощной салат" без орехов и лактозы;
   - каша/рис/спагетти/хлеб (крупа/мука) убраны у O (без злаковых) там, где
     стояли по умолчанию; O переведён на альтернативы без круп (печёное
     яблоко, йогурт, запечённые овощи);
   - у вегана (U) на горячее на обеде не было назначено вообще ничего -
     добавлена кефаль запечённая (рыба разрешена).

Открытые вопросы (не решались автоматически, т.к. в меню нет готовой
безопасной замены и правила прямо просят не изобретать блюдо без прецедента):

- Творожная запеканка на завтрак: клиентам с исключениями по
  лактозе/сахару/злакам (F, H, K, O, Q, S) эта позиция просто не
  выдаётся (без замены) - у них будет на 1 блюдо меньше на завтрак,
  чем у остальных. Если нужна замена - её должен утвердить кто-то с
  кухни/диетолог.
- Число в столбце E (БРАКЕРАЖ) оставлено пустым - по правилам оно не
  берётся из текста заказа напрямую, а уточняется отдельно.
